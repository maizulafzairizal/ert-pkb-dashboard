## 🏫 Tentang ERT PKB

**Emergency Response Team (ERT) Politeknik Kota Bharu** bertanggungjawab memastikan keselamatan dan kesejahteraan seluruh warga kampus dalam situasi kecemasan.

Sistem ERT PKB berasaskan **Incident Command System (ICS)** yang merangkumi:
- Pengurusan insiden kebakaran
- Pengurusan banjir
- Kecemasan elektrik
- Tumpahan bahan kimia
- Kecemasan perubatan
- Ancaman keselamatan
